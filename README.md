# EnglishHub — Learn English, Have Fun

A comprehensive English learning platform built with React, TailwindCSS, and Zustand.

## Features

### Learning Modules
- **Vocabulary** — 40+ words, categories, spaced repetition study mode
- **Grammar** — All 16 tenses with bilingual explanations (EN/ID)
- **Speaking** — Record yourself with guided prompts
- **Listening** — Audio exercises with comprehension quizzes
- **Reading** — Articles with inline vocabulary and quizzes
- **Pronunciation** — IPA sounds, minimal pairs, connected speech
- **American Accent Trainer** — R sounds, flap T, dark L, vowel shifts, linking, US vs UK, shadowing

### Smart Features
- **Smart Flashcards** — SM-2 spaced repetition algorithm
- **Real World Slang** — 15+ trending slang terms with origins
- **Slang & Corpus Analyzer** — Analyze text formality and register
- **Media Analytics** — Learn from movies, songs, and news
- **Context & Culture** — Scenarios, cultural notes, humor

### AI & Research
- **AI Pedagogy Partner** — Chat-based English tutor
- **Research Matrix** — Character analysis from literature
- **Pedagogy Tools** — Readability checker for drafts
- **Thesis Tracker** — Milestone timeline with deadlines

### Core
- **Dashboard** — Stats, streak, XP, Supervisor's Next Task widget
- **Dark/Light mode** — Toggle with system preference detection
- **Bilingual (ID/EN)** — Full Indonesian and English support
- **XP/Level system** — Track learning progress

## Tech Stack
- React 19 + Vite 4
- TailwindCSS 3
- Zustand (state management)
- React Router 6
- Lucide React (icons)
